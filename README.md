# boutique-hotel-dynamic-pricing
The project develops a web-based Information System for a boutique hotel that integrates room reservations with a dynamic room pricing engine.

#Tech Stack: ASP.NET Core with C# and MySQL.

#Main Roles:
- Guest
- Front Desk Agent
- Administrator

#Key Feature: Dynamic room pricing based on occupancy, lead time, and demand.

#Status: Requirements and design phase.
